# User test: "A few real users should finish the task unaided"

## The task

Each tester gets one card with a home visit written on it (newborn, pregnancy or mother after birth), opens the live link on their own phone or laptop, and must save the visit with the right danger result, **without help**. We note:

- did they finish unaided (yes / no)
- how long it took
- how they entered it (voice or typing) and in which language
- what, if anything, the reader got wrong
- one thing they said
